One word, the first that comes to mind: **kerfuffle**.

A commotion or fuss, especially one caused by a disagreement — surprising,
vivid, specific, and with a playful sound that rewards a second look.

Built for the [One Word, First Thought](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8) bounty on [make.fun](https://make.fun).

## How it works

`main.py` (Python 3, standard library only) writes the single word to
`$MAKEFUN_OUTPUT_DIR/entry.txt` — nothing else, no network, no extra files.
